**Problem Statement**
A food aggregator company has collected order data from registered customers on its platform. Acting as a Data Scientist, the task was to analyze this data and answer key business questions posed by the Data Science team — insights intended to help the company improve operations and customer experience.

**Approach**
Performed exploratory data analysis (EDA), including variable identification and data structure review
Conducted univariate analysis to understand the distribution of individual variables (e.g., order value, delivery time, ratings)
Conducted bivariate analysis to explore relationships between variables (e.g., cuisine type vs. order volume, restaurant rating vs. cost)
Derived actionable insights and recommendations based on the analysis to answer the business questions posed
**Skills & Tools**
Python
Exploratory Data Analysis (EDA)
Univariate Analysis
Bivariate Analysis
